for (p = first; p != NULL; p = p->next)
  free(p);

The problem is that p gets freed BEFORE for loop will execute "p = p->next"

So we need another pointer variable (temp)

p = first
while (p != NULL) {
  temp = p;
  p = p->next;
  free(temp);
}
